# 3D-Druckteile & Zubehör für Carten T410R

Dieser Ordner enthält eine Sammlung von nützlichen 3D-Druckteilen (STL-Dateien) für das RC-Auto **Carten T410R** sowie einen praktischen Wartungsständer.

## Enthaltene Dateien

### 1. Motorlüfter-Halterung (`fan_mount.stl`)
* **Autor:** [@kleinnconrad](https://github.com/kleinnconrad) (Eigene Konstruktion)
* **Beschreibung:** Eine maßgefertigte Lüfterhalterung für einen **50x50 mm Motorlüfter von Hobbywing**. Speziell entwickelt für die Montage im Carten T410R, um eine einfache Installation und optimale Kühlung des Motors zu gewährleisten.

### 2. LiPo-Akku Dummy (`lipo_mock.stl`)
* **Autor:** [@kleinnconrad](https://github.com/kleinnconrad) (Eigene Konstruktion)
* **Beschreibung:** Ein Platzhalter-Objekt in der exakten Größe eines **3S Hardcase LiPo-Akkus**. Dieses Modell eignet sich hervorragend, um die Einbauten, die Elektronik und das Kabelmanagement im Carten T410R besser planen zu können. So muss während der Bau- und Anpassungsphase nicht jedes Mal der echte, schwere Akku eingesetzt werden.

### 3. RC-Car Wartungsständer (`stojan_3dprint_25.stl`)
* **Autor:** [@Upgrade25](https://www.printables.com/@Upgrade25)
* **Beschreibung:** Ein stabiler Wartungsständer für RC-Cars (Maßstab 1:10). Ideal für Reparaturen, Setup-Arbeiten oder als Ablage.
